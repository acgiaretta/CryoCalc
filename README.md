# Calculadora das Neve ⛄❄️

Projeto prático desenvolvido com uma temática de inverno, integrando lógica de programação, manipulação do DOM e elementos gamificados.

## 📋 Sobre o Projeto
O usuário entra com o seu nome para iniciar o desafio. A cada rodada, a calculadora gera aleatoriamente uma expressão matemática (com as quatro operações básicas: adição, subtração, multiplicação e divisão), permitindo inclusive resultados negativos através do botão de inversão de sinal (`+/-`). 

O jogador dispõe de um cronômetro regressivo de **10 segundos** para inserir a resposta correta e somar 10 pontos. Se o tempo acabar ou houver um erro, uma nevasca destrói a calculadora (derrota). Se o jogador bater o recorde, um boneco de neve comemora!

## 🛠️ Tecnologias Utilizadas
* **HTML5**: Estrutura das telas e botões interativos.
* **CSS3**: Estilização temática, layouts em grid e animações de nevasca e tremor.
* **JavaScript (ES6+)**: Lógica do jogo, cronômetro (`setInterval`), geração de números aleatórios, manipulação do DOM e persistência local (`localStorage`).
